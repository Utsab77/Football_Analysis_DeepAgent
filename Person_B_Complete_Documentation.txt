5. PHASE 3 - PLANNING, MEMORY & SELF-CORRECTION (Weeks 5-6)
================================================================================

Role rotation point: implement planner and persistent memory modules.

5.1 TASK PLANNER (agent/planner.py)
------------------------------------
Implemented comprehensive planning system:

AnalysisPlan class with ordered steps
PlanStep with status tracking:
  • PENDING - Not started
  • IN_PROGRESS - Currently executing
  • COMPLETED - Successfully finished
  • FAILED - Encountered error
  • SKIPPED - Intentionally bypassed

Pre-defined templates for common tasks:
  • MATCH_PREDICTION_TEMPLATE (7 steps)
  • FORM_ANALYSIS_TEMPLATE (4 steps)
  • H2H_ANALYSIS_TEMPLATE (3 steps)

Features:
• Task decomposition from natural language
• Team name extraction from requests
• Re-planning on failure with retry logic

5.2 MEMORY SYSTEM (agent/memory.py)
------------------------------------
Two-tier memory architecture:

Working Memory (In-Session):
• Tool results storage with timestamps
• Step outputs for current analysis
• Context variables for LLM calls
• Clears at start of each session

Persistent Memory (Long-Term):
• JSON file-backed storage
• Records all completed analyses
• Stores team information for quick lookup
• Tracks failed operations
• Memory recall for previous analyses
• Automatic cleanup of old data

5.3 RE-PLANNING TRIGGERS
-------------------------
System triggers re-planning when:
• Tool failure (data unavailable, computation error)
• Missing information (required data not found)
• Quality threshold (confidence below minimum)
• Contradiction (model predictions disagree significantly)

6. PHASE 4 - SUB-AGENTS & CONTEXT MANAGEMENT (Weeks 7-8)
================================================================================

Implement specialized sub-agents and context compression system.

6.1 TEAM ANALYSIS AGENT (agents/team_analysis.py)
--------------------------------------------------
Analyzes single team performance:
• Recent form (points per game)
• Goals scored/conceded averages
• Strength rating
• League position
• Home/away performance splits
• Generates human-readable summary

Input: {team: str, before_date: str, n_matches: int}
Output: {team, form_points_per_game, goals_scored_avg, ...}

6.2 HISTORICAL ANALYSIS AGENT (agents/historical_analysis.py)
-------------------------------------------------------------
Analyzes head-to-head records:
• Total matches played
• Win/draw/loss records
• Average goals per team
• Recent trends (team_a_dominant, team_b_dominant, balanced)
• Notable results (high-scoring or significant wins)
• Generates H2H summary

Input: {team_a: str, team_b: str, before_date: str, n_matches: int}
Output: {team_a, team_b, total_matches, ...}

6.3 SCENARIO AGENT (agents/scenario.py)
----------------------------------------
Evaluates hypothetical changes:
• Key player absence impact
• Goalkeeper absence (higher impact)
• Formation changes (defensive/attacking)
• Home crowd boost
• Fatigue effects
• Custom scenario support
• Confidence scoring

Input: {home_team, away_team, match_date, scenario_type, custom_impact}
Output: {base_prediction, adjusted_prediction, impact_analysis, ...}

6.4 CONTEXT MANAGEMENT (agent/context.py)
-----------------------------------------
Rule-based context compression:
• Team stats → brief summary
• Form → points per game
• H2H → match count and trend
• Predictions → probability breakdown
• Context window management
• Summarization for agent consumption

6.5 RESULT AGGREGATOR (agent/aggregator.py)
--------------------------------------------
Combines outputs from multiple sub-agents:
• Team Analysis results (home and away)
• Historical Analysis results
• Prediction results
• Scenario Analysis results
• Key factors extraction
• Confidence score calculation
• Validation and consistency checks
